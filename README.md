# Antoine Ledoux — Portfolio

Bienvenue sur mon portfolio professionnel ! Ce site présente mes compétences, mes expériences et mes réalisations.

## 🚀 Technologies utilisées

- **React 19** — Bibliothèque JavaScript pour la construction d'interfaces utiliselles
- **Vite** — Bundler et serveur de développement ultra-rapide
- **i18next** — Support multilingue (Français/Anglais)
- **ESLint** — Linting du code pour maintenir la qualité

## 📋 Installation

### Prérequis
- Node.js (v18+)
- npm ou yarn

### Étapes

```bash
# Cloner le projet
git clone <url-du-repo>
cd antoine_portfolio

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Accéder au site
# Le site sera disponible sur http://localhost:5173
```

## 🔨 Scripts disponibles

- `npm run dev` — Démarrer le serveur de développement avec HMR
- `npm run build` — Générer la version de production
- `npm run lint` — Vérifier la qualité du code avec ESLint
- `npm run preview` — Prévisualiser la version de production

## 📁 Structure du projet

```
src/
├── components/      # Composants React réutilisables
├── pages/          # Pages principales
├── styles/         # Feuilles de styles
├── locales/        # Fichiers de traduction (i18n)
└── main.jsx        # Point d'entrée
```

## 🌍 Multilingue

Le site supporte plusieurs langues via i18next. Les fichiers de traduction se trouvent dans le dossier `src/locales/`.
